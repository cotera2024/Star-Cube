Minimal turret integration

This example uses the AssaultSentinel turret: it aims at the player (who follows the mouse) and shoots. Everything your game needs is commented here, step by step.

How it works · 4 pieces

  1. Import the class from its own file: import { AssaultSentinel } from '../src/assault_sentinel.js'
  2. Your player: an object with x, y, width, height and takeDamage(amount, type). That's the only contract the turret expects from the player.
  3. The services: the bridge between the turret and your world (who the player is, sound, explosions, damage). They're all optional — each module has a fallback if you don't provide them.
  4. The game loop: each frame you call update() (logic, bullets, shooting) and draw(ctx) (renders everything). That's it.

Want to try another entity? Change 2 lines and you're done
